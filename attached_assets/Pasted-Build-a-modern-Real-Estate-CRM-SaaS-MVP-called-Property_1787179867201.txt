Build a modern Real Estate CRM SaaS MVP called "PropertyFlow".

TARGET USERS:
- Real Estate Agents
- Property Dealers
- Real Estate Agencies

TECH STACK:
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- PostgreSQL-ready architecture

GOAL:
Help property dealers manage leads, properties, follow-ups and sales opportunities.

MVP FEATURES ONLY:
1. Authentication
2. Dashboard
3. Lead Management
4. Property Listings
5. Follow-Up Management
6. WhatsApp Integration
7. Deals Pipeline
8. Basic Reports

DO NOT BUILD:
- AI recommendations
- Property valuation
- Mortgage calculator
- Virtual tours
- Maps integration
- Multi-company support
- Mobile app
- Accounting system
